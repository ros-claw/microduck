# Duckverse game evidence

- `qualification/two`: ten fixed two-robot seeds, all outcomes retained.
- `qualification/four`: twelve fixed four-robot seeds.
- `heldout`: 32 unused-at-freeze seeds across four layouts, two cadences and four spawn rotations. Physical quality is 32/32; outcomes are 12 winners and 20 draws.
- `selected/{101,20008,20017}`: film-source audit and zero-error strict replay result. Heavy full-rate scene/trajectory/contact files are separate release assets.
- `rosclaw`: actual native action metadata, registered profiles, original audit digests, strict replay reports and existing Practice lineage/verification. No full model session, credentials or private reasoning is published.
- `development`: failed/incomplete prototypes, old contact failures and diagnostic source snapshot. These are not final quality passes or necessarily complete frozen replay packages.
- `source-snapshot.tar.gz`: frozen game/presentation source companion; recorded actor hashes remain the replay authority.
- `qa-summary.json`, `render-performance.json`, `media-checks.json`, `replay-tamper-checks.json`, `release-bundles.json`: compact review evidence.

Native actor policies are unchanged official stand/walk ONNX exports. No Jev, new policy training, Darwin promotion or hardware success is claimed. See `docs/duckverse/GAME.md`, `DEVELOPMENT.md`, and `ROSCLAW_INTEGRATION.md` for exact methods and limits.
