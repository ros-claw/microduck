# 最后一块地板：方法与复现

[English](GAME.md) · [发布素材](PUBLICATION.md)

四只 Microduck 在同一个 MuJoCo 世界内比赛。固定种子的塌陷安排不根据鸭子占位改变，先公开预警，再解除自由刚体地板的约束。每只鸭根据当前安全候选选择相邻地板，调用现有学习步态换格；支撑接触与姿态决定淘汰和冠军。角色名称表示独立实例，不表示已经训练出的性格。

## 物理与控制

- 一个模型与状态对象，四套独立的 14 关节运动运行时、56 个位置执行器；复用原生惯性及资产材质。每鸭质量 0.73724318 kg，关节力矩限制 ±0.6405 Nm，无根节点辅助力或外部施力。
- 地板宽 0.48 m、质量 0.8 kg，间隙 12 mm；初始由世界焊接约束固定。释放只改变 `eq_active`，下坠由重力与接触产生，不移动根节点或改写地板轨迹。下方 0.81 m 的可见接收平台承接跌落物体，但不算赛场有效支撑。
- 原生全碰撞模型及自碰撞保持开启；额外添加由真实视觉网格边界推导的无质量头部、躯干包围盒，外扩 0.5 mm。新增包围盒只排除同一只鸭，其余鸭、地板、接收平台均可接触。没有关闭鸭与鸭、鸭与地板碰撞。
- 使用 MuJoCo 3.12.0、4 kHz 积分、Newton 80 次迭代、0.5 ms 软接触参数及 libccd 路径。本项目拥挤落地用例实测改善，不代表 libccd 普遍优于原生求解路径。碰撞采用凸几何和软接触，允许有限微小穿透，不是逐渲染三角形碰撞。[MuJoCo 官方说明](https://mujoco.readthedocs.io/en/stable/computation/index.html#collision-detection)。
- 官方站立、步行 ONNX 策略以 50 Hz 更新关节目标。真实淘汰后，伺服保持实测关节角，避免站立策略继续对抗下方平台；不改写机器人位姿。胜者继续使用站立策略两秒，没有未经验证的庆祝跳跃。
- 战术只读取理想仿真当前位姿、承重脚底接触、公开预警倒计时、其他鸭当前位置。不能读取种子、未来释放时刻或塌陷排序。相邻候选需满足当前支撑时间约束，以距离、朝向、连通性、拥挤程度评分，途中重新检查合法性。这是确定性反馈基线，不是新训练的生存策略，也不是机载视觉。
- 裁判根据高度或持续失去有效赛场支撑判负；冠军必须唯一存活、直立且有稳定承重支撑。先处理全部淘汰再判定结果，无存活者为平局。比赛结束后停止后续释放，已经跌落的物体继续真实运动，不恢复任何约束。

提供方形、外围环形、厚十字和去角阶梯四种布局。常规节奏预警 5 秒、释放间隔 1.1 秒；快速节奏为 3.5 秒及 0.85 秒。预警可重叠。通过种子循环轮换四鸭与四个出生方向的绑定，策略参数和运动权重相同。

## 结果与限制

| 评测 | 种子 | 物理质量通过 | 冠军 / 平局 |
| --- | --- | --- | --- |
| 双鸭 | 501–510 | 10/10 | 4 / 6 |
| 四鸭 | 601–612 | 12/12 | 4 / 8 |
| 冻结后新 heldout | 20000–20031 | 32/32 | 12 / 20 |

质量门槛包含有限状态、无时间重置或求解器警告、无外部施力、力矩受限、最大接触穿透 ≤3 mm、穿透接触 P99 ≤1.5 mm。54 局全部通过，最大实测穿透 **1.797736 mm**，heldout 穿透接触 P99 最高 **0.001 mm**。这不是“游戏成功率 100%”；20 局 heldout 平局，说明当相邻候选全部即将失效时，当前基线仍可能没有逃生路线。

八种布局/节奏组合各四个出生轮换；22/32 局发生鸭与鸭接触。heldout 冠军为 lavender 1、cream 2、sky 2、graphite 7。样本不能证明各角色胜率相同或性格优劣。所有结果与接触极值见 [QA 摘要](../../artifacts/duckverse-game/qa-summary.json)。

四鸭仿真平均 **0.669×**，四鸭 ONNX 批次 P95 最高 1.80 ms；完整证据采用离线录制。视频播放倍率不等于物理运行速度。另有独立 [渲染性能测量](../../artifacts/duckverse-game/render-performance.json)。

## 复现与证据

按首页检出发行版本、下载锁定资产，使用 MuJoCo 3.12.0。

```bash
OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/run_duckverse.py \
  --seed 101 --players 4 --layout square --cadence steady --capture \
  --out artifacts/duckverse-game/my-seed101

.venv/bin/python scripts/replay_duckverse.py artifacts/duckverse-game/my-seed101
.venv/bin/python scripts/eval_duckverse.py --suite heldout --out artifacts/duckverse-game/my-heldout
```

输出目录必须不存在。完整录制保存每 0.25 ms 状态和控制量、全部接触的距离/力/位置/法向、50 Hz 公开决策、约束与裁判事件、源代码和策略摘要，需要较大磁盘空间。普通评测省略大型状态和接触流，但保留决策及审计指标。

严格重放重新执行闭环控制，逐项核验模型、状态、控制、全部决策与接触行、约束事件和裁判结果。三个视频源 seed **101、20008、20017** 的状态/控制误差均为零。另一次全新 GitHub 克隆、全新上游资产下载与独立环境安装也精确重放 seed 101；r1 修正历史资产路径后，105 项测试全部通过。原生 ROSClaw 开赛另有真实回执与重放证据。不同 gzip 文件的包装时间戳可能不同，接触内容以语义逐行核验。它证明仿真自洽，不证明真机效果。

本游戏没有 Jev 调用、新运动训练、Darwin 晋级或自主进化。人物偏好、多步路线规划、训练恢复动作、生存策略及实时交互界面仍属后续工作。旧 Demo 原样保留各自的局限；[失败实验](DEVELOPMENT.md) 不计入最终通过结果。
