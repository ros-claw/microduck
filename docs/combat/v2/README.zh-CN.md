## 实现方法

运动层沿用 V1 三个冻结模型：接触推进、侧闪、格斗步行，维持 **61 维输入、14 关节输出、50 Hz**。**本轮没有新训练运动权重或扩大 PPO**；新增部分是公开状态下的规则组合与可检查过渡。

短试探采用更近的入招距离、更短起手、较短推进及行程上限；重突进保留较大承诺。技能退出仍通过原策略的零指令制动。格斗步行中部分小幅指令会几乎停住，因此转向、后退及脱离改用已有 CPU 校验支持的运动指令组合，不过滤或平均关节策略输出。

动态衔接从侧闪的真实运动状态进入转向／反顶：必须有自己的足部支撑力、姿态、速度、角速度、关节状态及动作历史证据。公开头部姿态和前冲运动用于估计对手威胁，不能读取对手隐藏阶段。入口不合格则继续安全退出或制动；行走中短暂卸载与失稳分别处理。

团队调度器读取同一时刻公开状态，显式分配 `target + role + intent`，允许两鸭选同一目标，支持 PRESS_FLANK、PEEL_COVER、RESET_SWAP。目标承诺及切换迟滞减少反复换目标；身体动作可能晚于计划更新，只有实际保留目标、角色和计划并产生定向运动后的接触才计作合格介入。屏幕角色名称表示团队分派任务。

V2 使用独立 `duckfu.match.v2` 契约。旧 34 维／9 动作战术模型不兼容时直接拒绝启动，不补零或静默回退。当前 V2 高层是透明规则，未使用新 PPO、Jev 或网络大模型。

## 诊断与测量

十场旧对局用于开发诊断，输出动作掩码、阶段时长、结束原因、奖励组成和逐鸭时间线。离线“敌方收招参考窗口”中，制动／恢复锁定累计 69.46 鸭秒，未朝向累计 31.82 鸭秒。它们是排查线索，不是已经证明能完成反击的机会；敌方阶段只用于离线诊断。

旧 `VALID_STRIKE` 只在 ACTIVE 内观察，短接触的位移响应可能晚于收招。新增独立的离线响应审计，保留原事件，使用相同冲量／位移门槛并允许接触后 0.30 秒响应。只有已经结束的接触 episode 能提供冲量下界；未来冲量不能给过去的位移记功。后续其他接触会截断归因窗口。该审计是描述性辅助指标，不改奖励、裁判或轨迹，也不证明因果伤害。

团队介入审核另要求至少 0.12 秒、至少 3 cm 自身向原目标的实际移动，且接触时仍保持 PEEL 角色、实际目标与相关团队计划。原“换目标后发生接触”的四次候选，只有一次通过更严格审核。一次角色放弃后的碰撞、一次近乎同时发生的接触等被保留为未解决归因，不包装为救场。

## 结果摘要

本轮冻结执行代码为 `1e5f3a6`。80 项验证全部通过原数值门槛，最大接触深度 **1.313 mm**。这些包括 48 场双鸭短局、16 项动作课程和 16 场四鸭短局／课程，共 16 个不同基础种子；换边、对手与动作条件相关，不能当作 80 个独立种子。

- 站立目标课程中，试探完整动作周期中位数 **1.10 秒／17.35 cm**，重突进为 **2.06 秒／38.19 cm**。离线有效响应分别为 **6/8、8/8**；短招更轻、更快，但效果并非与重招相同。
- 对主动进攻规则的 8 场中，V1／全制动／动态版的干净闪避后响应分别为 **0／2／4 次**；对反击规则均为零。仅为小样本描述，未建立总体优势。
- 同一初态、同一敌方攻击的示例中，闪避 ACTIVE 结束至响应从 **2.74 秒降至 2.34 秒**，改善 **14.6%**，尚未达到预设 30% 目标。不同成功样本的条件中位数不能代替这项配对比较。
- 四鸭压力课程 8 场中出现 **1 次严格合格介入**；自由赛 8 场尚无合格介入。没有证明持续救援能力或压力缓解的因果效果。
- 选定双鸭 120,000 个状态、四鸭课程 160,000 个状态闭环重放误差为零；固定输入跨步长和闭环分岔另行披露。

完整数字、未达目标与步长结果见 [RESULTS](RESULTS.md)；[机器可读汇总](../../../artifacts/combat/v2/final-evaluation.json)保留接触候选与严格介入的区别。**207 项测试通过不替代真人观感验收。**

## 运行与复现

按 [V1 安装步骤](../README.zh-CN.md#本地运行与重放)准备锁定依赖与资产，在仓库根目录运行。输出目录必须是新目录。

```bash
export MICRODUCK_ROOT="$PWD/.assets"
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/run_combat.py \
  --config configs/combat/v2/selected_dynamic.yaml --brain rule --seed 91003 \
  --capture --out artifacts/combat/local/my-v2-duel
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/replay_combat.py \
  --run artifacts/combat/local/my-v2-duel
```

四鸭示例使用 `selected_team_course.yaml`、种子 93004；自由赛使用 `selected_team_free.yaml`、种子 92001。诊断工具为 `analyze_combat_engagement.py`；动作、过渡、团队与物理工具分别为 `probe_combat_actions_v2.py`、`probe_combat_transition.py`、`eval_combat_team_intents.py`、`probe_combat_physics_v2.py`，各自提供实际测试过的 `--help`。

本地完整状态较大，没有上传 GitHub。已有影片可直接观看；重新生成需要按冻结配置捕获，再创建新导演计划。记录中的绝对路径描述本地来源，不保证换机器后直接适用。
