## 3. 诊断得到的主要问题与处理

### 3.1 停稳流程确实占用了反击窗口

对十场既有对局增加动作掩码、阶段时长、结束原因、奖励组成和时间线分析。在离线“敌方收招参考窗口”里，制动／恢复锁定累计 69.46 鸭秒，未朝向累计 31.82 鸭秒。这些参考窗口用于定位阻碍，不能直接当作身体已具备执行能力的机会。

新增过渡检查读取自己的实际支撑力、身体速度／姿态、角速度、关节状态及动作历史。只有满足入口条件才从侧闪进入转向和反顶，不合格则保持制动／恢复。没有平均两个 ONNX 的输出，没有清空运动历史，也没有修改根节点状态。

### 3.2 部分“合法小指令”实际几乎不动

试验中发现小幅后退、纯转向等输入可能让当前运动策略停住，形成高层不断选动作、身体却没有进展的情况。改为使用已有 CPU 指令验证支持的后退、侧移与转向组合；同时修复绕侧角色到达侧面后仍围绕目标点停留、不能进入攻击的问题。

威胁判断也改用对手自身朝向本方的运动与可见低头，避免把“自己走近对方”造成的相对接近都误判为对方重冲。没有读取敌方隐藏阶段。

### 3.3 短招的物理响应会晚于 ACTIVE

旧检测器只在攻击 ACTIVE 内累计有效响应。开发案例里，真实接触已经发生，目标位移却在收招后约 0.06 秒才过阈值，因而漏判。

保留全部旧 `VALID_STRIKE`，另加离线响应审计：冲量、位移／失衡标准保持一致，接触后最多观察 0.30 秒；只使用已经结束的接触 episode 的冲量下界，防止未来冲量给过去位移记功；其他接触会截断归因窗口。这是辅助描述性指标，不改动作、奖励或裁判，更不是伤害因果模型。

### 3.4 换目标并碰到对方，仍不足以证明救援

规则团队调度器现在可以分派同一目标、正面压制／绕侧、解围／掩护和换位。加入目标承诺与迟滞，保持同一时刻公开快照。

进一步收紧团队介入审核：换目标后至少经过 0.12 秒，自己向原目标实际移动至少 3 cm，并在接触时保留 PEEL 角色、实际目标及相关计划。四个“换目标后接触”候选中，仅一个通过；立即发生的偶然接触、角色或计划已经变更后的碰撞均单列保留。

## 4. 冻结验证结果

执行代码冻结后，完成 80 项新验证：48 场双鸭短局、16 项动作课程、8 场四鸭自由赛、8 场四鸭压力课程。共 16 个不同基础种子；换边、对手和动作条件有关联，不是 80 个独立种子。

**80/80 通过原数值门槛，最大接触深度 1.313 mm。** 仍使用 8 kHz MuJoCo 物理、50 Hz 运动策略、原质量／惯性与 ±0.6405 Nm 力矩限制。没有新增击退力、无敌、预设胜者或碰撞豁免。

### 动作区分

| 指标 | 短试探 | 重突进 |
| --- | ---: | ---: |
| 课程数 | 8 | 8 |
| 完整动作周期中位数 | 1.10 秒 | 2.06 秒 |
| 完整动作路径中位数 | 17.35 cm | 38.19 cm |
| 旧 ACTIVE 响应计数 | 5/8 | 8/8 |
| 离线响应审计 | 6/8 | 8/8 |
| 动作内最差直立余弦 | 0.9974 | 0.9960 |

这证明了不同的运动轨迹和承诺，但没有证明匿名观察者已能辨招。短招的效果成功率也低于重招，不能只报更快而不报这一代价。

### 双鸭反击

| 对手 | V1 | V2 全制动 | V2 动态 |
| --- | ---: | ---: | ---: |
| 主动进攻规则：8 场中的干净闪避后响应次数 | 0 | 2 | 4 |
| 反击规则：8 场中的同类次数 | 0 | 0 | 0 |

计数不是获胜场数，也不等于完整资格化机会利用率。对主动进攻规则，两个 V2 变体各有四次 DOWN 事件，V1 为零；数值通过不能掩盖这种运动风险。

可直接配对的同一敌方攻击示例中，全制动与动态版的闪避结束至响应延迟为 **2.74 → 2.34 秒**，改善 **14.6%**；从闪避开始算，响应时刻为 6.36 → 5.60 秒。**尚未达到预设的 30% 配对改善目标，也未证明稳定整体优势。**

### 四鸭介入

严格审核后，压力课程八场中有一次合格介入，自由赛八场中没有。选定课程中，张三／ROOK 从莽哥／BOLT 转向稳哥／ANCHOR，保护对象为老六／SHADE；从 9.76 秒换目标到 12.3725 秒接触，自己向初始目标方向实际移动 0.398 m，接触时保持相关角色、目标和计划。

本轮没有合格的压力缓解或“救下一只本来必输的鸭子”的证据。团队分派已经能表达协作，但执行还不稳定，后续需要更持久的意图、更好的拦截与受干扰过渡。

## 5. 复现、数值敏感性与工程检查

- 207 项测试通过。
- 八支来源影片通过完整解码和逐帧物理来源映射检查；三支并排对照核对了输入帧数、50 fps、静音与文件哈希。
- 七组选定捕获与对应评估的控制、身体及阶段数组一致。
- 双鸭 120,000 个状态、四鸭课程 160,000 个状态闭环重放误差为零，接触及裁判日志一致。
- V1 在原冻结工作树重新执行，用于验证新分支仍保留同条件 V1 行为。
- 绳、跑酷、生存赛等旧执行目录没有改动。

跨步长检查仍披露差异：固定输入 0.4 秒窗口的最终根位置最大差异为 1.399 mm，鸭间冲量差约 5.54%。15 秒闭环在两个步长下都平局，但控制在 0.84 秒时已出现超过 0.01 rad 的差异，阶段在 2 秒分岔，后续位置分量差可达 0.380 m。不能因同为平局或同配置可精确重放，就称结果对步长不敏感。
