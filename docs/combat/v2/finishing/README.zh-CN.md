四只原生 Microduck 在同一个八角擂台自由进行 2v2。公开状态规则协调撤离、掩护与绕侧，学习运动网络驱动关节完成移动、接触和刹车，物理出界决定胜负。当前仍是待观感验收的可选仿真实验。

## 视频里发生了什么

**25.04 秒的完整比赛保持原速连续展示**，中间插入明确标记的回放。SHADE 撤离时，ROOK 接受掩护任务，在 13.72 秒从 ANCHOR 侧后方发生有效接触；ANCHOR 于 21.76 秒出界。BOLT 在 20.44 秒倒地，22.30 秒恢复，ROOK 换目标后于 23.62 秒再次从侧后方接触；BOLT 最终在 25.04 秒出界。**红队获胜，ROOK 与 SHADE 均留在场内。**

48.9 秒成片增加了开场预览、三段重点慢放和明确标记的结果定格。镜头、名字和小地图只读取记录状态；英语解说、接触触发的音效、原创合成伴奏与终场哨均为后期制作。另行延续 3 秒的真实模拟确认两只胜者都能保持支撑并停住，不改变比赛判决。

## 实施原理

- **战术层**：两队读取同一时刻的公开身体状态，持续分配压迫、牵制、撤离、掩护和绕侧任务，不读取对手内部相位、未来动作或评估种子。
- **终结与刹车**：站稳且承重的鸭子可以持续近身施压，最长 2.2 秒，并从内侧接近。边缘保护根据实测速度外推 0.35 秒，提前请求当前技能的零速度刹车，确认支撑与低速后再向内转移。
- **运动层**：新增原生对手 PPO 网络只用于 `finish_drive` 及其刹车；短顶、反顶、行走、闪避和恢复各用对应网络。共同接口为 61 维观测、14 维关节偏移、50 Hz 无额外滤波输出，切换时保留真实上一动作。
- **物理层**：四只机器人都保留原生 0.73724318 kg 质量、惯量、14 个限力矩伺服、自碰撞与地面接触，以及 70 个无质量部件凸包。队友也会碰撞，不通过根节点外力、传送、血条击退或弱点伤害倍率决定结果。

运动网络观察本体状态和物理命令，只有训练时的 critic 额外观察相对几何。这是“固定原生对手下的身体 PPO＋规则团队战术”，不宣称端到端学会了完整 2v2、用摄像头感知、由 Jev 实时决策或已迁移真机。

## 实训与挑战

四轮长训练共记录 **3,207,168 条环境采样**，不含小规模试跑和核验。最终固定输入标准化统计的版本完成了 256 个环境、251 次迭代；前面停止的训练按实际停止位置记录。定位到输入统计漂移后，保留原有 actor 输入尺度，继续训练全部 actor 权重及 critic。[采样统计](../../../../training/combat/finish-native/run-counts.json)、失败源码版本、训练日志、原始种子、选用的第 50 检查点、最终第 250 检查点及失败诊断检查点均有保留。

成片组合先冻结，再运行未参与挑选的 `220001..220004`。四个基础种子各交换一次左右，共得到每个组合 8 场配对比赛；换边、旋转和不同打法之间存在相关性。每场双方使用该条件的运动库，统计的是能否分出胜负，不是新网络战胜旧网络的场次。

| 留出自由对抗：同一 V4 战术与物理 | 原接触网络 | 专项终结网络组合 |
| --- | ---: | ---: |
| 数值核验通过 | 8/8 | 8/8 |
| 分出胜负 / 超时平局 | 4 / 4 | 5 / 3 |
| DOWN 事件 | 25 | 21 |
| 全程直立且不中断的闪避—扑空—反击序列 | 0 | 1 |

样本很小，事件数量也受比赛时长影响，不能据此宣称普遍胜率提高。独立原生对手专项中，“推出对手且自身最终停稳”是**原网络 11/24，新选网络 6/24**，因此没有把新裸网络宣传成全面升级。第 100/200/250 检查点、输入统计继续变化的失败版本、其他打法和更大擂台结果保留在[完整核验](../../../../artifacts/combat/v2/finishing/)中；展示组合通过独立配置显式启用。

**28 次留出执行全部通过原数值检查**，包括双方反击型、双方压迫型，以及半径 1.0 m 的混合打法。8 组旧/新同初态的完整积分状态逐位一致。三组额外打法分别有 2/4、1/4、1/4 场分出胜负，其余为平局；共享基础种子，不能当成独立胜率统计。

成片比赛最大数值穿透 **0.454 mm**，关节力矩上限 0.6405 Nm，无外加根节点力、模型未改写、无求解器警告。验收门槛保持最大穿透 3 mm、负接触子集 P99 1.5 mm。部件凸包和柔性数值接触仍是近似；“出界前发生接触”也不等于证明某一击单独导致了出界。

## 复现与交付

使用项目固定的 CPU 仿真环境与原生资产，从仓库根目录运行：

```bash
PYTHONPATH=src:scripts OPENBLAS_NUM_THREADS=1 python scripts/run_combat.py \
  --config configs/combat/v2/team_finish_showcase.yaml --seed 210001 --capture \
  --out artifacts/combat/local/reproduced-finish
```

然后按[英文说明](README.md#reproduce)核验赛后停稳、从记录状态渲染、添加英文声音并检查逐帧来源。完整故事板在 [storyboard.json](media/storyboard.json)；电影的 **2,445 帧**均对应真实积分状态，慢放不生成补间动画。

体积较大的二进制场景、逐积分状态和接触全文留在本地；仓库包含来源清单、事件、关节/身体轨迹、胜者延续核验、逐帧映射及[影片检查](../../../../artifacts/combat/v2/finishing/film-check.json)。交付仓库 **243 项测试通过**，训练补丁从干净基线重建 **14 项通过**。没有新建 Release、tag 或合并 PR。
