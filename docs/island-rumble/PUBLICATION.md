# Publication notes

中文标题：**四鸭抢岛：谁能守住最后的安全区？**

一句话说明：四只 Microduck 用学习步态争抢中心，真实脚底承重让地板累积开裂，也为独占安全区计分；对手的碰撞、进圈和跌落会改变场地与得分。

English title: **Island Rumble | Four Robot Ducks Fight for the Crown**

English description: Four Microducks share one MuJoCo world. Real loaded foot
contacts consume tiles; released constraints let gravity drop them. Only
exclusive, upright, loaded control of the centre circle scores; first to earn
1.5 seconds wins. Existing ONNX motor skills, deterministic tactics, no scripted
poses or predetermined champion. Simulation prototype with conservative collision
proxies; not new RL training or a hardware demonstration. The film uses one match,
with a labelled same-match hook, explicit rewind and event-based slow motion.
Original synthesized event cues are not recorded physical audio.

ROSClaw is the project framework and series context. This new game was executed
locally; the old game's native Agent receipt is not reused as this mode's proof.
Native integration verification for this mode remains pending.
