# 四鸭抢岛：踩踏改变场地，碰撞打断占领

[English](README.md) · [第一轮原型与失败规则](PROTOTYPE.md)

这一版把“等地板按剧本掉落”改成两个相互关联的真实机制：**脚底承重消耗地板；独占中心白圈、直立并且脚底实际承重，才积累占领时间。率先积满 1.5 秒获胜。**

这是明确命名的 **CrownRace 抢岛积分赛**。对手进圈、自己离圈、失去承重都会暂停得分；此前获得的积分保留。它不同于原版“最后幸存者”，也不同于要求连续站稳的 IslandClaim / CrownClaim。冠军产生时其他鸭子可以仍然存活；选中比赛最后还有三只鸭存活，视频不会把它说成“双鸭决胜”或全员淘汰。

## 方法与因果

地板都是有质量和自由关节的物理刚体，开局用世界焊接约束承托。只读取真实向上的脚底承重接触：法向力 >0.05N，向上法向分量 >0.5。120ms 滤波抑制尖峰，输入上限为三倍单鸭重量；损伤按 `滤波承重 / 单鸭重量 / 3.2秒` 累积。两鸭完整承重时，损伤约为单鸭的两倍。未踩的板不会因为随机时间表自动掉落。

损伤到 1 时仅解除约束，由重力和碰撞决定下坠，不修改位置或速度。裂纹和颜色依据记录显示损伤，属于有深度遮挡的显示标记，不增加承托物。

中央金色板从开局就是公开且永久的目标。3×3 正方形中，四个方向的出生位置到目标等距。第 2 秒开放积分；以躯干 XY 到中心的距离判定半径 8cm 的白圈。每个符合条件的 4kHz 物理步积累一个步长；没有脚底承重的微小间隙也不得分。两只鸭同时进圈都不得分，短暂腾空的对手仍可争夺。冠军记录在终态时冻结；之后的一秒物理收尾不算新比赛结果。

战术是公开当前状态上的确定性基线：Rusher 提前抢点，Survivor 偏好低拥挤路线，Blocker 尝试短时预测拦截。底层全部使用已有 50Hz ONNX 站立/行走策略，关节力矩上限 ±0.6405Nm。**尚未证明成功战术封锁，也没有新训练的推挤、横闪或跳跃技能。** 没有 Jev、位姿传送或外力辅助；使用理想仿真状态，不是视觉感知。

物理质量独立检查有限状态、无时间重置、无求解器警告、无施加外力、力矩 ≤0.640501Nm、穿透 ≤3mm。头部和躯干使用无附加质量的保守碰撞盒，其余复用原生凸碰撞模型；**不是逐可见三角形碰撞，也不宣称零穿模**。这是离线仿真，不代表真机通过。

## 复现与边界

完整安装、录制、严格重放命令见 [英文方法页](README.md#reproduce)。最终发布对应的双鸭证据目录为 `selected-two-current`，四鸭为 `selected-four`；模型、轨迹和逐步接触通过 Release 证据包提供。旧的 `selected-two` 保留在 `c77113b` 检查点，不能直接声称它来自最新源码。

先前连续安全岛规则四鸭为 0/32 冠军；后续连续中心占领开发试验为 14/32，仍未达标。一次开发批次末尾修改源码，导致已加载旧代码的 worker 为后续样本读到了新文件哈希；原始记录保留并在 `development-provenance-notes.json` 标记，不作为最终资格证明。当前增加导入、开赛和结束源码一致性检查；最终 32 局的源码哈希全部匹配选中录像，其选中 seed 的终态也与资格测试完全一致。

CrownRace 是公开的新规则，不能用它的 32/32 去宣称旧连续占领规则通过。旧模式、旧发布与历史失败全部保留。实测首次转向约 0.92–1.26 秒，首次换到新承重板约需 1.82–2.20 秒，因此没有用踩上 0.8 秒就掉落的无解设置制造刺激。

**新模式尚未通过 ROSClaw 原生 Agent 开赛与回执验证。** 之前 Last Duck Standing 的原生回执仍有效，但不挪作本模式的证明。当前也未验证真实硬件、Darwin 或自主进化。
