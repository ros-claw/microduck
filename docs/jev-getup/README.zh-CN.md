# 倒地恢复优化 · 英文影片审阅版

[English](README.md) · [新版英文影片](media/jev-getup-en.mp4) · [英文字幕](media/jev-getup-en.srt) · [实测与失败记录](../../artifacts/jev-getup)

这次重新运行了在线 Jev 比赛，改进的是实际运动控制。影片为 **108.10 秒、1280×720、50 fps**，包含 23 段按新比赛事件生成的英文体育解说，以及完整翻身、起身、站稳的慢动作特写。角色仍为 Dash、Waddles、Sly、Ace，保留原生材质和配色标识。

## 问题定位与修正

原控制只尝试一次坐站技能，失败后持续调用站立策略。原英文片中的 Dash 从仿真 49.16 秒进入恢复，到 91.673 秒淘汰，**42.513 秒始终没完成恢复**。只统计成功起身的耗时会遗漏这个失败，因此新统计同时包含完成、跌落时终止和比赛结束时仍未完成的恢复。

新版保留移动摔倒后的自然站立机会；如果仍翻倒，尝试最多 0.5 秒的已有学习翻滚技能，姿态恢复时提前结束。初始平躺仍保留经过校准的坐站动作。持续失败则在有界坐站、翻身与站立之间重新尝试，避免耗尽唯一一次机会后卡住。检测到姿态正在改善时，推迟技能切换。

起身后必须满足姿态、真实脚底支撑和低速度条件，随后站稳 0.3 秒，再用 0.5 秒逐步恢复行走指令。这些是本地运动反射，画面单独标注；Jev 继续选择抢点、截路、避让和撤退等战术目标。全部运动技能复用已有 ONNX 策略，本次没有训练新策略。

碰撞模型、4 kHz 物理积分、±0.6405 Nm 鸭子电机限制、逐块塌落和真实跌落淘汰规则均保持不变。没有复位根位姿、外力托举或碰撞豁免。

## 最终选局的实测结果

- 完成 6 次恢复，用时 **1.00、3.84、3.48、2.62、3.52、7.72 秒**。持续碰撞下仍有较慢恢复，不宣称任意摔倒都能秒起。
- 另 3 次恢复在 **0.22625、0.185、0.2225 秒**后随真实跌出台面而终止；没有再次出现原片那种长时间未完成恢复的情况。
- 连续低速翻倒且仍位于存留地板上方的最长时间，从原选局的 **8.48 秒**降至本局 **0.04 秒**。此指标不等于完整起身耗时，两局也不是同一随机轨迹的因果对照。
- 最大全接触穿透约 **1.644 mm**，无求解器警告，保持电机力矩限制。
- 完整闭环重放 **353,410 个物理步**，状态、控制、接触及决策一致，最大误差为零。

冻结控制器后，12 个新初始化姿态案例均在 **3.14 秒**内恢复。这是姿态实验，不是大规模对局胜率。两轮在线比赛、没有成功的技能组合、近十秒恢复的第一版，以及对照实验的近似初始化限制均保留在证据目录和英文方法页。

继承的 `RECOVERY_SKILL_STARTED` 记录原调度器的名义坐站阶段，`RECOVERY_ROLL_STARTED` 记录其翻身覆盖；**实际执行策略以 50 Hz 决策日志的 `policy` 字段为准**，影片状态卡也读取这个字段。
